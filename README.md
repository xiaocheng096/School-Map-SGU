# 韶乐园校园地图导览系统

一个基于单文件 HTML + 原生 JavaScript 的校园地图展示与坐标校准工具。界面采用"主页面 → 设置页面 → 二级页面"三层结构，分层收纳高频与低频功能。

---

## 📁 文件结构

```
map/
├── index.html          # 主程序（HTML + CSS + JS 全部内联）
├── map.jpg             # 校园地图底图（8000×5040）
├── 新建 文本文档.txt    # buildingsData 坐标备份 / 导入来源
└── README.md
```

无需构建、无外部依赖，双击 `index.html` 即可打开。

## �️ 页面结构与功能分层

### 设计思路

- **主页面**（高频使用）：查建筑、看地图、快速跳转，一眼即能操作。
- **设置页面**（低频 / 次要功能）：分类收纳显示、交互、数据与工具、关于。
- **二级页面**（坐标校准）：仅从设置页的"数据与工具"分类进入，避免误触发。

三个页面共用同一侧栏面板，通过 `.page-view.active` 切换显示。

### 主页面 `#page-main`

| 功能 | 说明 |
| --- | --- |
| 📍 查找 / 定位建筑 | 输入关键字精确或模糊匹配，按回车或失焦定位；也可按分区名直接定位（自动算中心点）。 |
| 🗺️ 地图操作 | 适应窗口 / 重置（回到默认缩放 + 居中） / 放大 + / 缩小 − |
| 🕒 最近使用 | 自动把最近 3 个定位过的建筑记录在 localStorage，点一下即可重定位。 |
| ⚙️ 应用设置 | 进入设置页面的唯一入口。 |

### 设置页面 `#page-settings`（按分类组织）

顶部有**设置搜索框**，输入关键字可实时过滤所有设置项的标题、描述与分类名；没有匹配时会显示"没有匹配的设置项"。

| 分类 | 设置项 |
| --- | --- |
| **显示** | 默认缩放级别、标记上是否显示分区标签、是否启用过渡动画 |
| **交互** | 点击标记是否弹出详情、滚轮方向反转、拖拽灵敏度（低 / 标准 / 高） |
| **数据与工具** | 坐标校准（进入二级页）、导出全部坐标数据（复制到剪贴板）、重置为初始数据（需二次确认） |
| **关于** | 版本说明、使用帮助 |

> 所有设置项修改后**即时生效并持久化**到 `localStorage`，下次打开自动恢复。

### 二级页面：坐标校准 `#page-calibrate`

**访问路径**：主页面 → ⚙️ 应用设置 → 数据与工具 → 「坐标校准」按钮

页面顶部带面包屑 `设置 / 数据与工具 / 坐标校准` 和返回按钮。

保留原坐标校准面板的全部功能：
- 待绑定建筑（输入查找）
- 名称 / 分区 / 类型 三项直接编辑
- 新增坐标（表单预设分区/类型）
- 删除坐标（二次点击确认）
- 复制全部坐标数据
- 重置初始数据

> 不再需要浏览器原生 `alert` / `confirm`，全部提示使用面板内的状态条；删除通过二次点击确认条实现，重置通过设置页的就地确认条实现。

### 关键设置项的确认机制

- **重置为初始数据**：点击后就地展开 `confirm-bar`，点"确认重置"才执行。确认条外任意点击会自动收起。
- **删除坐标**：首次点击「🗑️ 删除坐标」只提示，再次点才真删。

## 🧭 主页面 vs 设置页面分类逻辑

分类原则：**按使用频率划分**。用户 95% 的时间只做"查找 + 缩放 + 拖拽"，因此这些留在主页面；其余按功能聚类进入设置页：

| 留在主页面 | 进入设置页 |
| --- | --- |
| 查找建筑 | 默认缩放 / 分区标签 / 动画 |
| 适应窗口 / 重置 / 缩放 | 弹窗开关 / 滚轮反转 / 拖拽灵敏度 |
| 最近使用 | 坐标校准 / 导出数据 / 重置数据 |
| 设置入口 | 关于 / 帮助 |

## 🗂️ 数据结构

### `GRID_CONFIG`（网格配置）
```js
const GRID_CONFIG = { imgWidth: 8000, imgHeight: 5040, cols: 200, rows: 126, cellW: ..., cellH: ... };
```

### `buildingsData`（建筑坐标）
```js
{ id, name, zone, type, center: { x, y } }
```

### 设置持久化
```js
localStorage['campus-map-settings-v3']  // { defaultScale, showZoneTag, enableAnimation, popupOnMarker, reverseScroll, dragSensitivity }
localStorage['campus-map-recent-v3']   // [id1, id2, id3]
```

## 🔧 代码结构速览（index.html 内部）

1. **样式区** — `panel-header`、`page-view`、`nav-bar`、`section-block`、`switch`、`confirm-bar` 等
2. **侧栏 DOM** — 三个 `<section class="page-view">`（main / settings / calibrate）
3. **数据区** — `GRID_CONFIG` / `buildingsData` / `roadsData` / `INITIAL_BUILDINGS`（深拷贝用于重置）
4. **核心工具** — 坐标换算、视图变换、`renderMarkers`、`showPopup`、`refreshSelectOptions`
5. **页面切换与设置持久化** — `showPage()`、`loadSettings/saveSettings/applySettingsUI()`
6. **设置搜索** — 过滤 `.section-item` 与 `.section-block`
7. **重置确认条** — `#reset-data-confirm`
8. **最近使用** — `loadRecent/saveRecent/renderRecent/pushRecent`
9. **地图交互** — 滚轮缩放（支持反转）、拖拽（支持灵敏度）、点击拾取
10. **校准功能** — 查找、编辑三项、新增、删除、复制导出、状态条提示
11. **入口 init()** — 恢复设置 → 渲染 → 切到主页面 → 地图加载

## 💡 坐标校准工作流

```
主页面 → ⚙️ 应用设置 → 数据与工具 → 坐标校准
       → 输入查找 / 点地图标记选中
       → 点击地图新位置（即时绑定）
       → 改名称 / 分区 / 类型（改完即保存）
       → 新增 / 删除（列表维护）
       → 回到设置页 → 导出全部坐标数据 → 粘贴回源码
       → 返回设置页 / 主页面
```

## 🖥️ 响应式

- 宽度 ≤ 720px 时侧栏自动转为顶部 45vh + 地图底部 55vh 的纵向布局。
- 所有设置项、搜索框、确认条都是流动布局，不需要额外 CSS 媒体查询就能适应不同设备。

---

## ⚠️ 注意事项

- 所有坐标修改都在**浏览器内存**中生效，刷新页面会重置。完成校准后请点「📋 复制全部坐标数据」再粘贴回源码。
- 坐标取整使用 `Math.round()`，精度为 1 个网格单位。
- `buildingsData` 中 `zone` 若出现预设之外的值（如历史数据），下拉框会自动补入该项，不会丢失。
- 页面结构是**单页视图切换**（show/hide），不是路由；三个 `<section>` 始终在 DOM 里，切换很快。

---

## 🛠️ 可扩展点

- 更多分区 / 类型：修改面板 `<select>` 预设项即可。
- 标记尺寸：`GRID_CONFIG.cellW` 推导，全局联动。
- 更多设置项：在设置页新增 `.section-block` + `.section-item`，再加一条 `defaultSettings` 字段和 change 监听，即可自动进入搜索。
- 主题切换：把 `#0056b3` 定义为 CSS 变量，可扩展成浅色/深色两套。
