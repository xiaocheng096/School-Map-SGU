# 韶乐园校园地图导览系统

一个基于单文件 HTML + 原生 JavaScript 的校园地图展示与坐标校准工具，支持常规浏览和开发者校准两种模式。

---

## 📁 文件结构

```
map/
├── index.html          # 主程序（含所有 HTML / CSS / JS）
├── map.jpg             # 校园地图底图
├── 新建 文本文档.txt    # buildingsData 坐标备份 / 导入来源
└── README.md           # 本文档
```

> 所有样式和逻辑均内联在 `index.html` 中，无需构建，直接用浏览器打开即可运行。

## 🗺️ 功能概览

### 常规浏览模式

| 功能 | 说明 |
| --- | --- |
| 滚轮缩放 | 地图支持 5% – 200% 缩放 |
| 左键拖拽 | 按住空白处拖动平移地图 |
| 标记点击 | 点击红色建筑标记弹出详情气泡 |
| 快速定位 | 左侧下拉框按分区分组，选中即自动聚焦 |
| 适配窗口 | 「🎯 适配窗口」一键居中并缩放到合适尺寸 |
| 重置视图 | 「🔄 重置」恢复初始缩放与平移 |

### 开发者坐标校准模式

点击左下「🛠️ 开启坐标校准」进入校准模式，支持：

| 功能 | 说明 |
| --- | --- |
| 输入查找 | 顶部输入框可按名称模糊查找建筑（datalist 过滤） |
| 坐标绑定 | 选中建筑后点击地图，该建筑坐标**即时绑定**到点击位置 |
| 修改名称 | 「✏️ 建筑名称」输入框可直接改名 |
| 修改分区 | 「🗺️ 所属分区」下拉框可直接改所属区域 |
| 修改类型 | 「🏷️ 建筑类型」下拉框可直接改类型 |
| ➕ 新增坐标 | 填写名称/分区/类型预设后点击「✅ 确定」，再到地图上落点 |
| 🗑️ 删除坐标 | 选中建筑后点击删除（二次点击确认，防误删） |
| 📋 复制全部坐标 | 将当前内存中的 `buildingsData` 导出为 JSON，可粘贴回源码 |
| 状态条 | 所有提示都走面板内的 `.dev-status`，不再使用浏览器弹窗 |

### 分区与类型预设

- **分区**：善美区 / 明德区 / 知行区 / 思源区
- **类型**：教学楼 / 宿舍 / 食堂 / 公寓 / 公寓群 / 体育建筑 / 广场 / 湖泊 / 建筑

## 🗂️ 数据结构

### `GRID_CONFIG`（网格配置）

```js
const GRID_CONFIG = {
    cellW: mapWidth / cols,
    cellH: mapHeight / rows
};
```

地图使用网格坐标系统，`center.x / center.y` 以网格单位（cell）表示，渲染时通过 `gridToPixel()` 换算为像素。

### `buildingsData`（建筑坐标）

```js
{
    id: "AB10",              // 唯一标识
    name: "育德楼",           // 显示名称
    zone: "明德区",           // 所属分区（用于分组显示）
    type: "教学楼",           // 建筑类型
    center: { x: 67, y: 55 }  // 网格坐标
}
```

### `roadsData`（道路）

```js
{
    id: "R01",
    name: "大学路",
    grid_nodes: [[20,15],[60,30],...]   // 多段折线
}
```

## 🔧 代码结构速览

`index.html` 内部按区块划分：

1. **样式区** — 侧栏、地图容器、标记、校准面板、状态条等
2. **地图 DOM** — `#map-wrapper` / `#map-content` / `#map-image` / `#info-popup`
3. **常规面板 DOM** — 分区下拉、适配、重置
4. **校准面板 DOM** — 查找输入、名称/分区/类型编辑、新增表单、复制按钮
5. **数据区** — `GRID_CONFIG` / `buildingsData` / `roadsData`
6. **工具函数**
   - `gridToPixel()` / `pixelToScreen()` — 坐标换算
   - `applyTransform()` / `fitToWindow()` / `initMapView()` — 视图变换
   - `showStatus()` — 面板内状态提示（替代 alert）
   - `refreshSelectOptions()` — 重建常规下拉与校准查找列表
   - `renderMarkers()` — 渲染所有建筑标记
7. **事件监听** — 滚轮 / 拖拽 / 点击绑定 / 下拉定位 / 校准编辑 / 新增删除
8. **`init()`** — 入口，图片加载后渲染

## 💡 校准工作流

```
开启校准 → 输入查找建筑 → 选中 → 点击地图新位置（即时生效）
                         → 需要改名/换分区/换类型 → 改完即保存
         → 需要新增 → 填表单 → 点击地图落点
         → 需要删除 → 选中 → 点删除（首次提示、再次点才删）
         → 点「复制全部」→ 粘贴回源码
         → 点「❌ 退出校准模式」结束
```

---

## ⚠️ 注意事项

- 所有坐标修改都在**浏览器内存**中生效，刷新页面会重置。记得在完成校准时点「📋 复制全部坐标数据」再粘贴回源码。
- 坐标取整使用 `Math.round()`，精度为 1 个网格单位。
- `buildingsData` 中 `zone` 若出现预设之外的值（如历史数据），下拉框会自动补入该项，不会丢失。
- 编辑「善美区 ↔ 知行区」这类批量对调时，建议先在文本文件里做，再一次性替换进源码（参考上文 `新建 文本文档.txt` 的使用方式）。

## 🛠️ 可扩展点

- 更多分区 / 类型：修改面板中的 `<select>` 预设项即可。
- 标记样式：`.marker` 类已根据 `type` 区分颜色，可继续扩展。
- 道路渲染：`roadsData` 目前数据占位，如需绘制道路可在 `renderMarkers()` 旁边新增 SVG polyline 渲染。
- 标记尺寸 / 透明度：由 `GRID_CONFIG.cellW` 推导，修改网格尺寸即可全局联动。
